# Sitio Pro

Un skill para Claude que construye el sitio web de tu negocio, pensado para el mercado latino. Hecho por [AmplifAI Me](https://amplifaime.ai).

## Instalar

```bash
npx skills add AmplifAIMe/sitio-pro-skill
```

Luego dile a Claude: **"usa sitio-pro y hazme el sitio de mi negocio"**.

## Qué hace

- Te pregunta lo que necesita: negocio, giro, ciudad, WhatsApp, servicios, fotos, idiomas.
- Te propone uno de cinco diseños según tu giro, y quita las secciones para las que no tienes datos en vez de inventarlas.
- Arma el sitio con lo que tus clientes sí usan: burbuja de WhatsApp, botón de llamar, formulario de prospectos que puede llegar directo a tu WhatsApp, mapa, reseñas si tienes perfil de Google, español e inglés.
- Lo revisa (tipografía, color, contraste, accesibilidad, celular) antes de entregarlo.
- Lo publica gratis en Cloudflare Pages, si se lo pides.

## Sobre qué está construido

Sitio Pro no copia otros skills: los instala desde su fuente, con tu permiso y solo dentro de tu proyecto, y los pone a trabajar en orden. El crédito es de sus autores.

| Skill | Para qué |
|---|---|
| [Impeccable](https://github.com/pbakaus/impeccable) | dirige el diseño: planea, critica, audita y pule |
| [Taste Skill](https://github.com/Leonxlnx/taste-skill) | dirección de arte |
| [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | estilos, paletas y fuentes por giro |
| [Better Colors](https://github.com/jakubkrehel/skills) | paleta completa y contraste medido |
| [Frontend Design](https://github.com/anthropics/skills) | base oficial de Anthropic |
| [Emil Kowalski](https://github.com/emilkowalski/skills) | animación de interfaz |
| [GSAP](https://github.com/greensock/gsap-skills) | animación al hacer scroll |
| [LottieFiles Motion Design](https://github.com/lottiefiles/motion-design-skill) | principios de movimiento |
| [Remotion](https://github.com/remotion-dev/skills) | video promocional del sitio |

Cada uno conserva su propia licencia. Revisa la de Remotion si tu empresa tiene más de tres personas.
